### Release 2 of LYRX version 1.6.0.2 is available for download.

LYRX updates have been fast and furious over the last few weeks. This was not entirely unexpected; there have been dramatic changes to our graphics engine code in response to macOS Catalina. When changes to the foundation of your code base are required, as it has been in the case of LYRX 1.6 and higher, you’re always going to find issues that weren’t present in prior iterations.

The bright-side is that a lot of good has come of having to ‘dig deep’ into our code. We were able to apply various optimizations, which means LYRX is less taxing on system resources than any prior version. This means the ‘fun stuff’ we’re working on for future updates can be built on top of our new foundation with superior stability.

The new release 2 of version 1.6.0.2 addresses some issues, mainly on the windows side (AMD processor/graphics card related issues are a biggy), that we found with the help of a handful of customers and remote sessions with PCDJ development team members. Again, we can’t thank our customers enough for the assistance with seeking and destroying various problems that arose from the major changes 1.6 brought.
